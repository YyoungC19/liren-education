# 立仁校园的场景结构

- liren.tscn：校园主场景。F5 启动校园。
- scenes/maps/campus_map.tscn：地图场景。选择 Map，在检查器修改 Place 可预览五个区域。
- scenes/characters/player.tscn：科技技，含 AnimatedSprite2D、CollisionShape2D、Camera2D 和 NameLabel。
- scenes/characters/npc.tscn：cb，含 AnimatedSprite2D、CollisionShape2D 和 NameLabel。
- scripts/player_controller.gd：玩家移动与动画。
- scripts/npc_character.gd：NPC 名字与台词。
- scripts/campus_map.gd：地图绘图、碰撞与交互点。
- liren.gd：场景切换、E 互动和提示。

## 换人物外观

1. 双击 scenes/characters/player.tscn。
2. 点击 AnimatedSprite2D，再点击检查器里的 Sprite Frames 资源。
3. 在下方动画编辑面板替换每个动画的图片帧。
4. 保留 idle_down/up/left/right、walk_down/up/left/right 这八个动画名称。
5. 单张图片也可以用于全部动画；先换 idle_down 测试。
6. 调整 AnimatedSprite2D 的 Position 或 Scale 对齐脚底，不要缩放 Player 根节点。
7. CollisionShape2D 单独控制脚下碰撞，Camera2D 不受图片尺寸影响。
8. Ctrl+S 保存，再回到立仁场景按 F6，或者按 F5 启动校园。

cb 的外观在 npc.tscn 里同样替换；选 NPC 根节点可修改 Display Name 和 Dialogue。
校园主场景中的 NPC 只在进入教室时显示；打开独立 npc.tscn 能正常看到。
当前附带的是可替换的简单四方向像素占位素材。
旧 main.tscn 和旧练习脚本保留。
